# Project instructions

Personal website of Isrofil Amar, built with Laravel 13 and Blade, styled with Bootstrap 5.3. Version 1 serves content from PHP arrays; version 2 moves portfolio and blog content to MySQL.

@CONTRIBUTING.md

## Working rules

- Follow CONTRIBUTING.md for code, Git, and pull request conventions.
- Run the verification commands in CONTRIBUTING.md and report their output before proposing a commit.
- Ask before adding a dependency, a new top-level directory, or a configuration change outside the task.
- Keep changes within the scope of the current issue.
